# Cyberpunk backgrounds

Vlastní SVG pixelové assety vytvořené pro tuto hru, bez převzatých obrázků. Čtyři čtvrti × tři vrstvy (sky, far, near), 960 × 360. Generátor: scripts/build-backgrounds.mjs. Referenční screenshot sloužil pouze jako inspirace atmosféry. Každá vrstva se samostatně opakuje a posouvá v renderu.
